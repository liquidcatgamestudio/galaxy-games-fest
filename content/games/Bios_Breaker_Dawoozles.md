# **BIOS Breaker**

**Dawoozles**

A high adrenaline rhythm-platformer set in a corrupted system BIOS. Player's take control of a fast moving vehicle, a representation of a hotfix, created to rewrite the corrupt code plaguing the system. The corruption has infected core systems, turning the infrastructure of the BIOS into a fragmented and hostile environment.
<br></br>
Each level is linked to a music track handcrafted for the BIOS by DopoGoto
<br></br>
All hazards within react to the beat of the music. Every moment lives and breathes through the soundtrack, an audio-visual feast for the senses.
