# **Super Alpha Tai Chi Game**

**Square Storm Interactive**
<br></br>
What if magic was real? What if all around us, there were invisible energy particles just waiting for us to use them? This game puts you into that world! There is a real underlying "physics" system for all the spells you cast. No need to memorise dial-up gestures that need to be executed perfectly. Here, you can shoot fireballs with your own style. Here, you can discover new spells the developer didn't even know could happen! This is Super Alpha Tai Chi Game [working title].
